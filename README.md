# Zabbix Cat or Problem Widget

## Опис (UA)
Цей віджет для Zabbix 6.0+ відображає активні непідтверджені проблеми. Якщо проблем немає, замість порожнього екрана ви побачите випадкове фото котика або собачки. Клік по фото оновлює його!

**Особливості:**
- Відображення списку активних проблем.
- Автоматичне завантаження фото тварин при відсутності проблем.
- Можливість підтвердження (acknowledge) проблем прямо з віджета.
- Блимання для нових проблем.

## Description (EN)
This widget for Zabbix 6.0+ displays active unacknowledged problems. If there are no problems, instead of an empty screen, you will see a random photo of a cat or a dog. Clicking on the photo refreshes it!

**Features:**
- Displays a list of active problems.
- Automatically loads animal photos when no problems exist.
- Ability to acknowledge problems directly from the widget.
- Blinking effect for new problems.

## Встановлення / Installation
1. Завантажте файли репозиторію.
2. Скопіюйте папку в директорію `ui/modules/` вашого Zabbix.
3. Перейдіть в `Administration -> General -> Modules` та натисніть `Scan`.
4. Увімкніть модуль "Cat or Problem".
